## 🇧🇷 Português

### Sobre o projeto

Este projeto é uma **recriação do website da Zentry**, desenvolvido como um exercício de desenvolvimento frontend, explorando interfaces imersivas, animações e interações avançadas.

A proposta foi reproduzir a experiência visual e interativa do projeto original, realizando também uma **localização completa do conteúdo para português brasileiro**.

O projeto foi desenvolvido utilizando **JavaScript e Vite**, com **GSAP** para as animações e interações presentes ao longo da página.

O resultado foi publicado na **Vercel** e pode ser acessado através do link acima.

### ✨ Principais características

* Interface inspirada no website da Zentry
* Conteúdo adaptado para português brasileiro
* Animações e transições utilizando GSAP
* Animações baseadas em scroll
* Elementos interativos
* Transições entre seções
* Efeitos de entrada e saída de elementos
* Tipografia e composição visual inspiradas no projeto original
* Uso de cores vibrantes e contrastantes
* Layout responsivo
* Desenvolvimento utilizando JavaScript moderno
* Build e desenvolvimento utilizando Vite
* Deploy realizado através da Vercel

### 🛠️ Tecnologias utilizadas

| Tecnologia     | Utilização                                      |
| -------------- | ----------------------------------------------- |
| **JavaScript** | Lógica, interações e comportamento da interface |
| **Vite**       | Ambiente de desenvolvimento e build             |

### 🎨 Animações e interações

Um dos principais objetivos do projeto foi explorar o uso de animações para criar uma experiência mais dinâmica e próxima de interfaces modernas e imersivas.

O **GSAP (GreenSock Animation Platform)** foi utilizado para controlar diferentes comportamentos visuais, incluindo:

* Animações de entrada de elementos
* Transições entre componentes
* Movimentação de elementos durante o scroll
* Efeitos de escala e transformação
* Animações sequenciais
* Microinterações
* Controle de timing e easing

A utilização de animações foi pensada para complementar a experiência de navegação, evitando que os elementos simplesmente aparecessem de forma estática.

### 📱 Responsividade

O layout foi desenvolvido considerando diferentes tamanhos de tela, buscando manter a experiência visual e as interações consistentes em:

* Desktop
* Tablets
* Dispositivos móveis

### 🚀 Executando o projeto localmente

Clone o repositório:

```bash
git clone https://github.com/BeThomazzi/zentry-ptbr.git
```

Entre no diretório:

```bash
cd zentry-ptbr
```

Instale as dependências:

```bash
npm install
```

Execute o servidor de desenvolvimento:

```bash
npm run dev
```

O Vite disponibilizará a aplicação localmente, normalmente em:

```text
http://localhost:5173
```

### 📦 Build para produção

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar o build localmente:

```bash
npm run preview
```

# 🇺🇸 English

### About

This project is a **recreation of the Zentry website**, developed as a frontend experiment focused on immersive interfaces, animations and interactive experiences.

The original website's content was fully adapted to **Brazilian Portuguese**, while the visual language and interactive experience were recreated as closely as possible for study and portfolio purposes.

The project was built using **JavaScript and Vite**, with **GSAP** powering the animations and interactive behaviors throughout the page.

It was deployed using **Vercel** and is available through the live demo link above.

### ✨ Features

* Zentry-inspired interface recreation
* Full Brazilian Portuguese localization
* GSAP-powered animations
* Scroll-based animations
* Interactive UI elements
* Section transitions
* Element entrance and exit animations
* Vibrant color palette
* Responsive layout
* Modern JavaScript
* Vite development environment
* Vercel deployment

### 🛠️ Tech Stack

| Technology     | Purpose                                |
| -------------- | -------------------------------------- |
| **JavaScript** | Application logic and interactions     |
| **Vite**       | Development environment and build tool |
| **GSAP**       | Animations and transitions             |
| **HTML5**      | Semantic structure                     |
| **CSS3**       | Styling, layout and responsiveness     |
| **Vercel**     | Deployment and hosting                 |

### 🎨 Animation & Interaction

A major focus of this project was creating a more dynamic and immersive browsing experience through animation.

**GSAP (GreenSock Animation Platform)** was used for:

* Element entrance animations
* Section transitions
* Scroll-based movement
* Scaling and transformations
* Sequential animations
* Microinteractions
* Timing and easing control

The animations were designed to complement the interface rather than simply decorate it, creating a more fluid and engaging navigation experience.

### 📱 Responsive Design

The interface was developed to provide a consistent experience across:

* Desktop
* Tablet
* Mobile devices
